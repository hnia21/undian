Atur Hasil Undian Berikutnya

Masukkan satu atau beberapa nomor grup (pisahkan dengan koma) untuk mengatur beberapa undian ke depan sekaligus, misalnya 5, 12, 3. Nomor pertama yang ditulis akan keluar pada undian berikutnya, nomor kedua pada undian setelahnya, dan seterusnya. Kosongkan seluruh antrian untuk kembali ke mode acak murni.

Status Undian Grup (Mode 2)

Input di bawah hanya tersimpan sebagai data admin dan tidak muncul di halaman utama. Data ini adalah vlookup undian grup: saat nama grup yang sama diketik di halaman utama, urutan pengundian dan nomor yang tampil mengikuti NO di sini (NO terkecil diundi duluan). Edit langsung, tambah/hapus baris, atau tempel dari Excel, lalu Simpan. Tombol "Hapus Semua Data Grup" TIDAK menghapus konfigurasi ini — gunakan tombol "Hapus Konfigurasi Nomor Urut" di bawah untuk itu.

Impor Dari Excel (Input Massal)

Copy sel dari Excel lalu tempel di kotak bawah. Kolom pertama = NO, kolom kedua = NAMA GRUP (pisah kolom pakai tab / koma / titik-koma; tiap baris = satu grup). Baris header seperti "NO / NAMA GRUP" otomatis dilewati.
